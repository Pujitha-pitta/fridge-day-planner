# Fridge Day Planner

A fridge-friendly daily planner: keep the household's plans visible, mark them done, and add new ones in seconds.

## Run it

Open the [live Fridge Day Planner](https://pujitha-pitta.github.io/fridge-day-planner/) on the tablet or phone you want to keep by the fridge. No build step or account is needed.

## Use it by the fridge\n\n- On Android, open the site in Chrome and use the browser menu to install it or add it to the home screen.\n- On iPhone or iPad, open it in Safari, tap Share, then Add to Home Screen.\n- Keep the device plugged in and use Full screen. Keep screen awake works in browsers that support the Screen Wake Lock API.\n- Plans are stored on this device only. The app does not sync to other household members’ phones.\n\n## Features\n\n- Fridge-side tablet and phone layout with large touch targets\n- Installable PWA shell with offline app loading

- Browse days and jump back to today
- Add and edit plans with a time and category
- Mark plans complete or remove them
- See daily progress at a glance
- Save plans in browser local storage
- Responsive layout for phones, tablets, and landscape screens

## Privacy and limitations

Plans stay in the browser's local storage on this device; they are not synced between devices. Clearing site data removes saved plans. The sample plans appear on first use for today and can be edited or removed.

## Tech

HTML, CSS, and vanilla JavaScript.
